Todo / 日历 / 定时任务

提醒与定时执行依赖本机 Snap 运行。

Obsidian

连接已有 Vault，浏览、创建和编辑 Markdown。授权 Agent 参考笔记，把研究与任务成果写回知识库。

基于 Markdown 文件，不包含完整的 Obsidian 插件体系。

Agent 能力

交代目标，先讨论或制定计划，再推进执行。过程中可补充要求、暂停任务，并检查文件与产物。

项目管理

将会话、资料、规则和工具放进同一个项目。连接本地目录，从准备好的环境继续研究、写作或开发。

Skills 与 MCP

用 Skill 复用常用方法，通过 MCP 连接工具与服务，也能使用本机 CLI。按项目配置任务需要的能力。

外部工具需具备相应依赖、账号与访问权限。

项目记忆

将偏好、背景和长期约定留在可查看、可编辑的记忆文件中。规则与记忆分别管理，继续工作时少些重复解释。

子会话与主会话

将研究、审阅和检查拆成子任务，追踪会话关系与运行状态。收到结论后，继续原来的子会话跟进修改。

探索能力

从选定回复另开探索，继承分叉前的上下文，研究其他假设与解法。将有用结论引用回主会话，继续推进。

带回探索引用，不自动合并文件修改。

文件、改动与终端

在任务旁预览文件、检查 Git 改动，通过 worktree 隔离代码任务。打开可见终端运行或调试，随时检查产物。

Office 以预览和内容提取为主，复杂格式需回到原应用核对。

A FEW THINGS TO KNOW

开始之前，
你可能想知道。

关于使用方式、数据与演示的几个说明。

Snap 和普通聊天窗口有什么区别？

Snap 把项目目录、规则、记忆、工具和工作产物组织到桌面工作台中。Chat 适合讨论与问答，也能使用已配置的工具；Agent 则围绕任务连续执行，并提供文件、终端与轨迹等检查入口。已有 Chat 可以迁移到 Agent 继续。

AI 说明会一直调用模型吗？

不会。轨迹里的 AI 说明默认关闭，需要时才开启，并产生额外模型用量。有 Agent 任务运行时，说明请求会排队；成功说明会缓存。它基于公开的任务、操作和结果解释步骤，目的属于推测，原始详情仍可直接核对。

定时任务需要一直开着 Snap 吗？

需要。提醒和定时执行依赖本机 Snap 运行；配置好项目、执行内容与时间后，可以从运行记录查看每次任务的结果。

我的笔记和资料放在哪里？

项目文件、会话与记忆保存在本机。Obsidian 接入直接使用 Vault 中的 Markdown 原文件，授权后 Agent 可读写相应内容。调用外部模型、MCP 或其他服务时，任务所需内容会发送到相应服务，具体范围取决于任务和配置。

这些动态演示展示的是什么？

动态演示基于更名前版本 0.19.71 的真实操作录屏，发布素材中的品牌文字已后期统一为 Snap。部分等待经过剪辑或加速，业务操作与执行流程保留原录制内容；本次没有重新录制或重跑模型。演示可随时暂停，也可以放大查看细节。
