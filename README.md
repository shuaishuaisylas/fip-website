# Snap 宣传网站

[在线查看](https://shuaishuaisylas.github.io/fip-website/) · [产品功能说明](docs/index.html)

Snap 是围绕项目上下文、工具执行和知识沉淀的桌面 Agent 工作台。官网以真实操作录屏介绍 11 项能力，重点展示上下文、执行轨迹与 AI 说明、Todo 和 Obsidian。

## 设计与内容

1.1.3 精简 11 项功能的介绍：保留标题与单段说明，移除重复标签、引导句和列表，必要边界保留短注。桌面文字与演示采用 30 / 70 布局，手机紧凑纵排；视频与播放交互保持不变。

页面版本 **1.1.3**。沿用 1.1.0 按用户提供的设计规范完成的版式，采用暖纸色画布、墨色正文、400 字重标题、4px 小圆角与克制的橙色链接强调；以左右交替的产品画面和文字介绍展开功能。Snap 蓝色图标保留原始品牌形状。

- `index.html`：官网页面，内含样式与交互脚本。
- `assets/videos/` 和 `assets/posters/`：11 组真实操作录屏与封面。
- `assets/brand/snap-logo.png`：Snap 品牌图标。
- `assets/fonts/`：本地 Inter 字体及 OFL 许可；中文使用设备字体回退。
- `docs/index.html`：同风格的公开功能说明。

演示进入可视区域后静音循环，内嵌画面隐藏原生播放器工具栏，提供暂停与放大入口。减少动态效果偏好会阻止自动播放，仍可手动播放。

演示基于更名前版本 0.19.71 的真实操作录屏，发布视频与封面中的品牌文字已由 Fip 后期统一为 Snap。部分等待经过剪辑或加速；此前已裁切窗口外缘并清理左上角操控浮标。品牌文字属于后期处理，业务操作与执行流程保留原录制内容，本次没有重新录制或重跑模型。原始 MOV 保持不变，发布素材不作为当前 Snap 版本未经编辑的原生画面。

媒体缓存版本为 `?v=1.1.1-snap`；本次未修改 11 组视频与封面，播放交互保持不变。

本站只展示产品介绍和本地视频，不启动 Agent、不请求模型，也不读写项目或 Obsidian Vault。

## 本地预览与发布

无需安装依赖。可直接打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8000
```

GitHub Pages 使用 `main` 分支的根目录 `/`。推送更新后会自动重新发布。分享或移动页面时请保留 HTML 与 `assets/` 的相对位置。
